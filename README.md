### About

I'm a software engineer at **Enosis Solutions**, where I build enterprise **CRM and PDS platforms** for North American clients. RESTful APIs and microservices in C#, .NET Core, and Entity Framework against MS SQL Server, with React on the front end, and I own features from requirement analysis through design, implementation, review, and release.

Before that I spent a year at **Scale AI** on **prompt engineering and RLHF** for code generation models. I wrote adversarial and edge-case prompts to surface reasoning failures, reviewed over a thousand AI-generated snippets for correctness and security, and curated the fine-tuning datasets that came out of it. It's where most of my LLM and NLP experience comes from, and it shaped how I read code.

I've been solving algorithmic problems since my first year of university. Codeforces Expert, CodeChef 4★, 2500+ problems across the major judges, two ICPC Dhaka Regional appearances, and a few contests I've set and judged myself. It shows up in the work: I notice the O(n²) before it ships.
